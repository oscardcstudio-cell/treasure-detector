================================================================================
COMMANDES D'EXÉCUTION (référence)
================================================================================

Installation (une fois) :
  cd tools/prep
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt

Vérification setup :
  bash test_setup.sh

Phase réelle (4 étapes) :
  source .venv/bin/activate
  python3 download_mnt.py      # → data/derived/mnt_lidar_raw.vrt
  python3 derive.py            # → hillshade/svf/lrm/openness.tif
  python3 to_pmtiles.py        # → 4 fichiers .pmtiles (z12-17)
  python3 georef_cadastre.py   # Squelette (T3.2+)

POC (simulation) :
  python3 proof_of_concept.py  # → REPORT_POC.md
